# Responsive_Menu_06
A simple responsive menu made using HTML5 and CSS3.
About the Project

This is my sixth web development assignment. I created a responsive navigation menu using HTML and CSS.

Features

- Navigation bar
- Home, About, Services and Contact links
- Horizontal menu on desktop
- Vertical menu on mobile
- Hover effect
- Responsive layout

Technologies Used

- HTML5
- CSS3

Files

- "index.html" - Contains the navigation menu structure.
- "style.css" - Contains the styling and responsive layout.

Concepts Used

- CSS Flexbox
- Media Queries
- Flex Direction
- Hover Effects
- Responsive Design

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.

What I Learned

- Creating navigation menus.
- Using CSS Flexbox.
- Making menus responsive.
- Using media queries.
